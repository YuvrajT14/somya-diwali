# AGENTS.md

## Project context

This is a user-owned TanStack Start app built with React 19 and plain JavaScript. It uses Vite for local development and Nitro for Vercel builds. Start with `README.md` for local setup and deployment notes. Keep changes focused and preserve the existing routes and Diwali experience.

## Key files

- `src/routes/__root.jsx` renders the HTML document and shared providers. There is no `index.html`.
- `src/routes/*.jsx` contains file-based pages. `src/routes/api/*` contains public server routes.
- `src/lib/server-fns.js` contains TanStack server functions.
- `src/start.js` configures TanStack Start middleware.
- `src/server.js` is the TanStack Start server entry.
- `src/router.jsx` creates a QueryClient per request; do not move it to module scope.
- `src/routeTree.gen.ts` is generated by the router plugin. Never edit or commit it.
- `vite.config.js` configures TanStack Start, Nitro, and React. Keep their plugins in place.
- `vercel.json` identifies the project as TanStack Start for Vercel.
- `src/index.css` and `tailwind.config.js` contain the app's design tokens and styles.

## Server security

- Every server function and server route is a public HTTP endpoint. Validate all inputs and authenticate callers before accessing private data.
- Treat authorization as server-side work. A page gate, hidden button, or client check does not protect a server endpoint.
- Do not return or log request headers, cookies, access tokens, or secrets.
- Store secrets in Vercel environment variables and read them only in server-side code. Do not expose secrets through `VITE_*` variables.
- Set shared cache headers only when the response is identical for every visitor.
- Prefer server functions for app-initiated RPCs. Use server routes for HTTP URLs requested by browsers or external services.

## Working notes

- Use `npm ci`, `npm run dev`, `npm run build`, and `npm start` as documented in `README.md`.
- Run `npm run lint` before finishing code changes.
- Write JavaScript and JSX only. Do not add `.ts` or `.tsx` files; `src/routeTree.gen.ts` is the generated exception.
- Keep server and first client renders consistent. Access `window`, `document`, and browser storage only in effects and event handlers.
